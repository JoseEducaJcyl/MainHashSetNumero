# Demostración de HashSet - Números sin Duplicados

## Descripción
Aplicación simple en Java que demuestra la propiedad fundamental de HashSet: **no permite elementos duplicados**. Se añaden números con repeticiones y se comprueba que el conjunto final contiene solo valores únicos.

## Funcionalidades
- Crear un conjunto (Set) de números enteros
- Intentar añadir elementos duplicados
- Demostrar que HashSet rechaza automáticamente los duplicados
- Mostrar los elementos únicos resultantes

## Tecnologías
- Java
- HashSet
- Set (interfaz)
- For-each
